# Blocked and separately scoped release work

Prepared 2026-09-20 from `todo.md`, `docs/quality/BUILD_STATUS.md`, the LIVE specification, publication checkpoint and security model. This file does not approve public publication or close a release gate.

These are intentionally excluded from the six ready production tasks. Distinguish external blockers from engineering/design prerequisites: not everything below merely needs a secret or user answer.
